One original sentence that replaces an entire pointless meeting — after
this line, nobody can justify holding the meeting at all.

> The decision was already made in the email thread, so this meeting is just thirty people watching one person read it out loud.

## Run

```bash
python3 main.py
```

This writes the entry to `/output/entry.txt`, guarded to the competition
gate (UTF-8, 1–200 characters, a single line, not only whitespace) and
verified by reading the file back.
